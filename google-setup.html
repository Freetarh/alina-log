Tilslut Google Kalender

Dette er en engangsopsætning for familiedashboardets Google-forbindelse. Du kan udføre den fra telefonens browser, men Google Cloud er nemmest i browserens skrivebordsvisning.

1. Opret Google-projekt

  1. Åbn Google Cloud Console. Vælg eller opret et projekt til familiedashboardet.
  2. Gå til Google Calendar API og vælg Enable / Aktivér.
  3. Åbn Google Auth Platform og opsæt appens navn (fx Familiedashboard) og kontaktmail. Vælg External, hvis I bruger almindelige private Google-konti.
  4. I appens testbrugere skal du tilføje både din egen og Batouls Google-mailadresse. Hvis Google kræver valg af dataadgang, skal appen kunne se og redigere kalenderbegivenheder samt se kalenderlisten.
  5. Under Clients opretter du en OAuth client ID af typen Web application. Tilføj redirect-adressen nedenfor under Authorized redirect URIs (ikke som JavaScript origin).

Google OAuth redirect URI:

Gem Client ID og Client Secret fra Google Cloud. De skal ind i Supabase som hemmelige værdier, aldrig i GitHub eller almindelig app-kode.

2. Supabase Edge Function Secrets

Åbn Supabase-projektets indstillinger for Edge Functions og find Secrets.

Opret følgende tre hemmelige værdier:

  1. GOOGLE_CLIENT_ID – Client ID fra Google Cloud
  2. GOOGLE_CLIENT_SECRET – Client Secret fra Google Cloud
  3. GOOGLE_TOKEN_KEY – krypteringsnøgle, som du genererer nedenfor

Generér en kryptografisk tilfældig 32-byte AES-nøgle direkte i din browser. Værdien bliver ikke sendt til vores server fra denne side.

Vigtigt: Hvis nøglen ændres, kan eksisterende Google-forbindelser ikke længere dekrypteres. Gem derfor nøglen sikkert. Del ikke Client Secret eller krypteringsnøglen i chat eller GitHub.

Hvis appen ligger på en anden adresse end https://freetarh.github.io/alina-log/, skal du også tilføje GOOGLE_APP_RETURN_URL med den faktiske HTTPS-adresse.

3. Forbind konti og vælg fælles kalender

  1. Åbn familiedashboardet og log ind som dig selv. Gå til Kalender → Google Kalender → Forbind min Google-konto.
  2. Godkend Googles adgang. Gentag derefter på Batouls telefon med hendes familielogin og hendes egen Google-konto.
  3. Opret en ny, separat Google-kalender til fælles familieaftaler via Google Kalender (eksempelvis Familie), og del den med den anden person med skriverettigheder.
  4. I familiedashboardet vælger ejeren denne separate kalender under Fælles Google-kalender. Brug aldrig en privat primær kalender her.
  5. Tryk på Synkroniser fælles Google-kalender. Aftalerne vil derefter vises i familiens kalender.

I Googles testtilstand udløber kalenderens refresh tokens normalt efter 7 dage. Det betyder, at Google-kontoerne muligvis skal forbindes igen, indtil Googles produktionskrav er opfyldt.
